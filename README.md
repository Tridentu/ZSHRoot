# ZSHRoot for Tridentu 2

## What is this?

ZSHRoot is a Zsh environment that is based on Oh My Zsh. However, it is light than OMZ because it loads plugins only on demand.

ZSHRoot also makes using the terminal (let alone zsh itself) easier by adding aliases and necessary tools for everydays tasks in the terminal.

## Features

- Many improvements to a **VARIETY** of tools (such as man pages)
- Syntax highlighting
- Tmux support
- Starship prompt by Default
- Atuin out of the box.
- Quick access to sudo (via escape key)
- ENV VAR browsing via Ctrl-B
- Venv support
- change themes on the fly
- Colored Help info
